# AYYUR — démo de 30 secondes (soumission Space Apps)

Film muet de **29,7 secondes**, en anglais, avec sous-titres à l'écran. Il se termine sur le lien du site : **ayyuur.vercel.app**.

- Les durées de chaque plan sont dans `js/video-timing.js` (total < 30 s, règle du concours).
